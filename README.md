# AI 实操教程视频工作流

一套从定稿、角色设计和录屏到剪辑、发布与复盘的 Codex Skill。适合用一个真实案例讲清 AI 工具或软件的操作流程。

## 开始使用

1. 把 [ai-tutorial-video-workflow](skills/ai-tutorial-video-workflow/SKILL.md) 整个 Skill 目录连同 `references/` 和 `assets/` 放入你的 Codex Skill 目录。
2. 在项目对话中输入“用 `$ai-tutorial-video-workflow` 做一期中文实操教程，项目入口在这里，我的受众是第一次用这个工具的人。”
3. 接续旧项目时附上交接入口、当前剪辑版本和要修的范围。没有安装 Skill 时，可在对话里直接给出 `SKILL.md` 路径。
4. 用[项目记录模板](skills/ai-tutorial-video-workflow/assets/project-records.md)留存采纳、核心证据和当前一步。剪辑工具、品牌参数和素材由各自项目提供。
