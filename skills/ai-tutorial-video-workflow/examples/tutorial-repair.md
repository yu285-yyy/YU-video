# 示例 · 导入表格的局部剪辑修复

练习场景。以下素材和时间点用于检验流程，可用自制表格及录屏重做。

## 输入

42 秒横版教程。用户只授权改 00:12–00:22 的表格导入，并准备自行导出。正式旁白和字幕已采用。现有录屏 A 保留导入菜单，录屏 B 保留导入结果。用户说点得太快，中间点击未拍到。

## 操作

1. 找到这支 42 秒的已采用时间线，复制成修订版，记录确认过的母带和字幕。比对两个源段。用 1× 看 00:10–00:24，并在实际语音中定位“导入”和“出现三列数据”。
2. 列出证据：A 中能读菜单和目标项，B 中能对到那三列。复查可否同工作区、同界面补录菜单点击、文件选择和结果响应。先试着补到一个覆盖动作两端的真实段落。
3. 如果已补录，将操作前菜单交给旁白，在点名控件时用一次短框，接真实点击及页面响应，再留够读表头的时长。把加载空等从源段缩短，复查 00:12 和 00:22 两个边界。
4. 如果暂时补不到，用可核实的菜单画面与结果画面，保留连续旁白。需要额外中间说明时，制作标明“操作示意”的短图形。将未拍到的点击登记在复查表里。
5. 打开实际可编辑版本，检查链接素材、相关轨道可编辑、全片仍为 42 秒。按对象与检查范围分别记技术检查、该段 1× 和是否已进行整期播放。用户自行导出。

## 合格的交付摘要示例

> 此次交付剪辑器中的修订时间线，修改 00:12–00:22，复看的相邻范围为 00:10–00:24。正式音轨和字幕仍对齐。读屏检查记录了目标菜单的可辨时点和结果表头的阅读窗口。中间点击待补录，当前使用已录菜单与结果做对照。该版由你审看并导出。
