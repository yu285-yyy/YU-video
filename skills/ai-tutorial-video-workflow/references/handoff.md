# 交接、发布与迭代

## 接续入口

维护一个可快速读取的交接页，指向本期采用稿、正式母带和字幕、视觉规范、实录索引、当前工程或导出、审片记录、发布素材及下一步。每件核心产物写版本或日期；账号默认与本期临时覆盖分开记录。已有项目状态机制时在交接页给出入口，采用信息仍由原状态文件管理。

开启新对话时用一个短请求带上项目入口与当前任务。例如“按 ai-tutorial-video-workflow 接续这个项目，先读交接入口。现在只复查第一章实录和旁白的对点。”

## 发布物料

- 封面第一眼说明教程主题，第二眼说明观众能完成的动作或获得的结果。借鉴对标的短标题和构图，套用自己的品牌、例子和真实成果。横竖版独立排版，检查缩略图与标题安全边距。
- 主页常驻物料统一角色和字标。头像按圆裁和典型小尺寸检查；横幅把主要角色及字标保留在预期裁切安全区。主页简介说明长期提供的内容。
- 首发正文按受众问题、实际示例、能跟做的步骤组织，附与本期相关的话题标签。正文中的操作、结果、观看收益与实录核对。发布状态按实际操作登记。

## 更新这套流程

1. 记录哪一期、哪个镜头或哪个交付步骤暴露了什么问题，保存内部证据位置。
2. 写下采用过的改法、复核结果及适用范围。仅适用于账号、题材、平台、版本或工具的内容写回对应资料。
3. 通用改动只修改一个主入口或必要的参考和模板。用一个新任务验证可照做，并检查旧项目仍能续接。更新发布仓库的变更记录。
4. 发布 PR 时写问题、改动、验证和适用范围。匿名示例可附前后变化描述。公开仓库的提交内容应能独立应用，示例采用可再分发的材料并说明来源。
