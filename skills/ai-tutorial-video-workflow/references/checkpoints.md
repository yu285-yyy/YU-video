# 从选题到时间线的工作步骤

用于整期制作或跨对话恢复。已有办法能提供相同证据时沿用已有文件。不依赖特定的剪辑器、图像生成服务或音色。

## 1. 题目验收

先写出观众当前的任务、卡点和完成结果。实际走一次流程，优先选择能拍到操作结果、能用同一例子贯穿各段的案例。在操作清单里写环境、入口、必要权限和成功判据。以结果检验选题，例如导入一张表后能看到日期按月分组。

交接物：一句承诺、演示材料、操作清单与取证缺口。候选题只记录采用范围和决定依据。

## 2. 定稿、配音与时间基准

先写故事路径：看见卡点 → 用当期材料做 → 亲眼看到结果 → 同样的方法用到另一份材料。英文控件在第一次真正用到时解释名字、用途和何时点。口语审稿读出声，逐句检查谁在做什么、动作有没有落到实录。

给剪辑的稿件包含章节和取证提示；给配音的文本是实际朗读内容。保存采用的两者、正式音频、字幕和词点证据。更换母带时，根据新声重核字幕、词点、跨段分配和旧素材取段。局部画面返修时以既有母带和字幕为准，必要时明确更新影响。

交接物：已采用的口播、纯朗读文本、母带与源音频索引、字幕、关键动作词点。

## 3. 按动作去采实录

每个操作留五项：开始状态，目标控件，真实输入或点击，应用响应，能读清的成果。连续实录持有操作和反馈的顺序。静帧可证实当时画面可见的状态，图示用明示标记解释原理或缺失步骤。环境、账号或版本不同会影响按钮时提前决定是否补录、换环境或调整脚本。

实录以全窗交代位置，需要时另出局部。当场检查光标、弹窗、页面响应、字号和读屏停留。敏感字段按制作需要处理，确保完整步骤仍可辨。截图、旁白写法或箭头各自有证据边界。

交接物：录屏路径、源起止和关键帧位置、可放大的目标区域、目标操作与读窗、需要补录的动作。

## 4. IP 和视觉样片

调取确认过的母版。统一发型与配饰的解剖侧、体态、服装、品牌字标、文字和画幅。给插画参考标注其用途，例如身份、空间、笔触、动作。局部返修以已采用的图为起点，改完核对关系最密切的部位和整体识别。新场景验角色手、物件抓握、遮挡和相互位置。素材库按意义选择，分别记录可换内容模板、独立素材、须拆出的旧镜和仅参考的例子。

A-roll 要做一件事并把视线交出去；B-roll 给看得清的真实操作和响应；MG 或文字用于取舍关系或并列解释。优先实制一个带正式配音的跨镜样本，至少让观众看见“角色引出 → 真实动作 → 结果或阅读”。说明布局与颜色变化发生在哪里，播放时观察字标、角色、控件和字幕。

交接物：采用的视觉说明、样片与确认范围、分层资产和可换字段。

## 5. 分工、统装与续接

总控交给录屏、设计和画面制作共享的正式音频时基、章节区间和实际交付件。实施过的镜头至少有一行来源、词点、主视觉动作和下镜接棒。表格可直接使用[模板](../assets/project-records.md)。

跨对话恢复最先查生效工程、时间线或发布文件，并逐项核对采用的稿、声、字幕、角色和旧稿使用范围。文件路径、编辑器内媒体 ID 与项目 ID 分开登记；进入新工程要重连并在时间线上查看。标明引用的是工程、试样、抽查、导出或用户确认。采用版落地在工程上后再记恢复状态。

交接物：可编辑时间线、依赖索引、修改段及上一版本、技术检查和实际观看记录。导出方式待定时可以继续做可编辑工程与可逆复核，到交付时再登记实际选择。
