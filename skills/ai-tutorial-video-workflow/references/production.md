# 制作与验收

## 1. 定稿与取证

- 用观众遇到的具体卡点开场。确定教程结束时能亲自完成的结果。完整走一遍流程，记录环境、测试版本、使用的项目与必要权限；对着实际结果改稿。
- 拆成有目标的句组。给每个操作写清开始画面、所点控件、页面反馈和结束状态。录屏保留动作前的上下文和结果停留，另收一张可用于放大的控件证据。缺失的动作优先补录；可验证的前后状态可做对照，图示画面明确标示。交付里记下缺失步骤和替代证据能支持的范围。承诺或正式旁白需要变更时先确认变更范围。
- 记录正式旁白的文件和版本、拼接点或变更范围。字幕与真实发声对齐；关键视觉点用实际语音定位。遇到识别结果和文稿不同，先听词及前后句，再定字幕或补音。

## 2. IP、画风与素材

- 建立角色基准图和项目可调用的资产索引。以角色自身的左右标注首饰、分发方向等识别特征。对照定稿检查换机位后的解剖侧、手腕、物体接触和遮挡。字标配色及安全区来自品牌规范。
- 比对参考时记录可借鉴的构图、材质、信息读序和节奏。按照自己的主题、角色和素材组织画面。新画风先审代表静帧，再试做一个实际配音句组，覆盖 A-roll 引出任务、B-roll 实录反馈和读结果的完整接力。
- 复用镜头模板前先明确这句需要观众认位置、看顺序、看对比还是理解因果。把新版文案、正式词点和真实控件填入模板，记下采用条目、范围和检查结果。

## 3. 画面与声音剪辑

- A-roll 承担讲述、提问或动作引导。给角色一个完整表达窗口，让手势、视线和场景道具指向下一镜。场景中人物和道具保持同一透视与接触关系。B-roll 承担步骤及结果，真实操作窗优先居中并保留足够控件尺寸。
- 重复画面用画面职责的切换处理。可按段落让两套有明显色差的底色接力，两套均带相同品牌标识。在片头和章节交界保住运动连续性，给读字与界面反馈留时间。
- 口播出现「点哪里」「看哪里」或说到关键状态时，给真实控件一个占主导的提示。箭头、局部高亮或小 IP 都可用。提示随词点出现并在当前操作结束后让位。小 IP 可用体量小的说话标志配合口播，避开控件及字幕。
- 区分实录空等、有效阅读、手势动作和结果。先去空等，用局部推近、点击到反馈或前后对照增加信息；阅读段保持画面稳定。画面调时要复查进入帧与退出帧、源动作及相邻镜头。
- 旁白、音乐和提示音分轨。疑问音可放到问题的转折，短叮可标记命中，确认音可托住结果。按口播关键词和画面反馈一起选点，先保证旁白可懂。

## 4. 审片证据

| 检查 | 至少记录 |
| --- | --- |
| 技术连续性 | 当前版本、分辨率、帧率、时长，片头换色、段端空隙、意外黑帧与可见跳变。可获取时检查实际帧时间戳，并区分源录屏帧重复与合成出帧问题。 |
| 字幕与口播 | 视觉锚点、实录时刻和发声词点的抽查位置。核听歧义词、拼接点及音乐音效是否压过旁白。 |
| 1× 全片 | 从头到尾听看，并记录需要阅读的停留、无信息段、节奏累积、眼睛能否追到控件和跳变位置。技术通过、局部抽看和全片审看分别写结论。 |
| 交付确认 | 可编辑时间线或实际交付的文件、参考的上一版、用户自行导出或代导出的决定。可编辑项目需核对正常入口可打开、素材可重连、用户需要改的轨道可编辑。缺失的观看、导出、发布或指标记录保持待核验。 |
