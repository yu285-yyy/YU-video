# 返修手册

先记版本、时段、用户看到的症状、相邻镜头和本次是否允许改声音或字幕。做一处能观察到差异的维修，再判断哪些段共享这个问题。记录判断依据和影响范围。

| 症状 | 先看什么 | 可执行的处理 | 验收 |
| --- | --- | --- | --- |
| IP 出了场，观众仍记不住 | 角色停在哪里、完成了什么动作、手和眼把注意力交给谁 | 给主角色完成一组有目的的动作和一句完整讲述。实录阶段在安全区用小 IP 或说话符号接力。 | 观众能看清角色动作和下一镜目标，小 IP 离开当前控件和字幕。 |
| 画面单一，换底又跳 | 单一颜色和重复版式持续多久，换底处前后有没有接续 | 信息职责变化时换底或取景。选两套有清楚色差的底色，共用字标和内容窗。外框缓变时把内容操作保在连续镜头里。 | 看换色的前、过渡、后，品牌和内容位置都可辨，1× 连续播放顺。 |
| 静了很久，看着像等待 | 当前静止服务阅读、真实等待，还是无新增信息 | 保留有效读窗。根据源事件删加载或空等，局部看菜单、输入、点击和反馈。使用真实前后对照补出结果。 | 读窗够用，页面状态顺着动作走。剪点音画仍同步，用户能自己找到目标。 |
| 一直翻页或过渡太多 | 一次变化新增什么信息 | 先合并无信息变化；在同个界面利用光标、局部取景或响应推进；章节交接再用独立转场。 | 看一整章判断频率，含相邻切点，确认注意力跟随操作。 |
| 箭头多、音效很吵 | 旁白点名的对象及同一时刻所有视觉和听觉提示 | 只选一个主视觉指向，绑定真实像素位置。疑问给转折，叮给定位或命中，确认给实际结果。短提示触发一次，留出人声。 | 盯着正常大小预览，记录箭头与声响出现在关键词或响应的哪里。 |
| 口播与画面字幕各说各的 | 正式 WAV 的发声词点、SRT 区间、实际操作入点和反馈 | 先校采用的母带与字幕；在固定时基内挪画面取段或提示。需要调整口播时记录新的影响区间。 | 两端和转折句逐段检查，确认涉及的字幕及人声在同一版。 |
| 有卡顿或掉帧反馈 | 源录屏画面、帧率、相邻画面边界、实际编辑器播放 | 比对同段源与合成，可用解码和 PTS 定位黑帧或帧时间问题。若合成时间戳规整，记录是否为源重复画面、界面加载、镜头停顿或预览性能。 | 技术检查、软件预览、1× 观看分别写结论和范围。平均帧率只说明一种属性。 |
| 录屏缺点击，只有结果 | 现有实录、补录可能和旁白承诺 | 优先补录。有对应真实状态时提供可辨的前后对照；图示明确标识。需要改定稿承诺时询问采用范围。 | 记清采到的信号、缺口影响和用户可见的交接说明。 |

## 三次查看同一个区间

1. 先以正常速度看画面和听旁白，写出确切卡点。
2. 分开检查正式声音、原始实录、候选合成和字幕，记录各自的证据类型。在时间线逐帧找边界问题时同时检查相邻画面。
3. 回到可交付的工程再连着播放。检查修改和继承范围，说明是否有全片观看证据、是否已经导出及谁负责下一步。
