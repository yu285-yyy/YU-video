# 中文实操教程视频

交付一支让目标观众能按步骤复现结果的视频。每期先确定一个具体问题、一份贯穿全片的实际材料，以及观众能验收的结果。

## 先接上现有工作

1. 确定需求是做新一期、接续已有版本，还是只改一项。接续时从项目入口读取最近采用的文稿、旁白、画面规范、工程版本、已核对证据和下一步。已有状态文件时沿用其状态与决策记录。工程入口或媒体链接失效时先在当前工作区或编辑器定位；还有缺口时集中索取工程入口及所缺素材。既有决定够用就从实际卡点开始。
2. 新项目先记录受众、问题、结果、素材来源、目标画幅及交付方式。品牌、角色和画风从项目已确认的规范读取。只改一项时读取该环节相关的输入。
3. 先核对源素材和实录能覆盖的操作。素材缺口会影响教程承诺时，优先缩小承诺或补录该动作。用真实证据标出处与范围。

## 从定稿到交付

| 阶段 | 进入下一步前留下的产物 |
| --- | --- |
| 选题与定稿 | 一句话承诺、一份可复现材料、采用版口播和操作清单。核实词汇、入口和实际结果。 |
| IP 与画风 | 角色母版、品牌字标和配色、构图与画幅。新风格先做代表静帧，再用实际配音试一段含操作与结果的交接。 |
| 录屏、配音与字幕 | 记录真实录屏来源，锁定采用的旁白母带和字幕，建立词点、点击与画面反馈的对应关系。 |
| 镜头与剪辑 | 句组、画面新增信息、证据锚点、阅读窗和相邻镜头接棒。解说与实操用不同画面职责，共用同一品牌；短提示随词点出现。 |
| 审片与交付 | 技术核对与 1× 连续观看分别记证据。交付用户选择的可编辑工程或导出文件，并注明已审范围和下一步。 |
| 发布与复盘 | 核对横竖封面、发布文案及实际成片的承诺。记录本期使用资产、可复用经验和可验证的下期改进。 |

制作、实录或审片时按需读[制作与验收](references/production.md)。准备接续、发布或更新 Skill 时读[交接、发布与迭代](references/handoff.md)。填写[项目记录模板](assets/project-records.md)时保留用户已有的文件结构和状态字段。

## 保持可维护

- 每次返修围绕一组可描述的观看问题，使用可回退的版本，保留上版工程或快照。画面改动后复查相邻界面状态、口播及字幕。每次交付只对实际检查过的内容作结论。
- 验证过的通用改进进入 Skill 与更新记录，账号辨识、个人音色、授权素材及编辑器项目位于各自项目。公开复现案例使用可分发素材或原创占位，并记录权利和来源。
